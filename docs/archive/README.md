# Historical planning archive

This directory preserves superseded planning drafts and reviewer messages for
provenance. They are not active instructions.

Authoritative project documents are:

- `docs/IMPLEMENTATION_PLAN.md` for the scientific workflow;
- `docs/DECISIONS.md` for approved decisions;
- `docs/tasks/` for bounded execution specifications;
- `docs/reviews/` for review records and reconciliations;
- `docs/handoffs/` for executor instructions.
