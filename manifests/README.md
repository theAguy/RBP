# Manifests

This directory contains small, versioned descriptions of large immutable inputs
and frozen data partitions. It must not contain the 724 MB CSV itself.

`dataset_audit.json` is generated by:

```bash
PYTHONPATH=src python3 -m rbpbench.data.audit \
  --csv dataset_K562_multilabel_with_NEGs.csv \
  --output manifests/dataset_audit.json
```

`sequence_partition_environment_002a.{yml,explicit.txt,json}` record the
isolated `rbpbench-splits-002` conda environment (pinned Bioconda MMseqs2
`18.8cc5c`, build `h8b377d6_0`) used for Task 002A's real-binary tiny-fixture
gate — see `docs/SPLITS.md`.

`sequence_decode_002b2.json` is the sanitized acceptance evidence for the
first full real-data decode: frozen input/tool hashes, three retained FASTA
hashes/sizes, exact/reverse-complement duplicate summaries, and resource
measurements. The large decoded artifacts remain under the Git-ignored
`artifacts/` tree.

`sequence_partition_environment_002c3_arm64.explicit.txt` is the exact
`osx-arm64` package lock bundled for the offline Task 002C-3/4 collaborator
run. It contains the native MMseqs2 `18.8cc5c` build already accepted during
Task 002B after the Intel build failed on Apple Silicon.

`sequence_partitions_002c_v2.json` is the small tracked closure record for the
final leakage-audited benchmark split. It binds the successful Darwin return,
final membership hash, component/partition counts, label-floor and balance
disclosures, and the zero-violation audit summary. The large membership and
edge artifacts remain under the Git-ignored `artifacts/` tree.

`task003a_split_validation_report.json` is the sanitized closure record for the
supervisor-facing split-validation package. It binds the frozen Task 002C
inputs, the main report, technical appendix and provenance hashes, headline
reconciliations, and the model-blind/no-split-mutation execution boundary. Full
tables, PDFs and high-resolution figures remain under the Git-ignored
`artifacts/` tree; the short Markdown report and four supervisor-facing SVG
figures are versioned under `docs/reports/`.

`task003b_environment_003b1.{json,lock.txt}` records the isolated Python 3.12
environment for the simple prevalence, GC, 3-mer and sparse 6-mer baselines.
The environment is created locally under `.venv-003b-baselines/`, which remains
Git-ignored.

`task003b_pilot_003b2.json` is the sanitized acceptance record for the
eight-protein train-to-validation pilot. It freezes the nine selected C values,
input/output hashes, aggregate development metrics, local resource profile,
numerical repeat evidence, and the proof that no test label or feature was
accessed. Row-level predictions remain under the Git-ignored `artifacts/` tree.

`task003b_phase_a_003b3.json` records the accepted final Phase-A refit. It binds
the complete hash-inventoried coefficient/scaler generation for all 122
proteins, 1,098 converged logistic fits, fitting-label and resource summaries,
and the proof that Phase B and all test interpretation remained unstarted.

`task003b_simple_baselines.json` closes Task 003B. It binds the single
authorized Phase-B test evaluation, all aggregate and per-protein metrics, the
Git-ignored row-level predictions, GC-matched sensitivity results, balance
disclosure, independent metric reproduction, and the explicit boundary that
the former ResCNN and external competitors remain unrun.

Future files include coordinate mappings, eligibility summaries, and frozen fold
assignments.

`source_files.json` records every original project artifact, including large
files excluded from ordinary Git:

```bash
PYTHONPATH=src python3 -m rbpbench.data.inventory \
  --list configs/source_artifacts.txt \
  --output manifests/source_files.json
```
